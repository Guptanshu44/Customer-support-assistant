## 🚀 Quick Reference: The 5 AI Superpowers

1. **Professional Reply Suggester (`coach.py` & `client.js`):** Generates polished enterprise draft replies adhering to 6 hard rules (plain text only, zero emojis, no echoing customer messages, no filler phrases, multi-turn greeting awareness, context-driven escalation).
2. **Agent Burnout Detector (`burnout_detector.py`):** Turn-by-turn calculation of agent emotional stress and cognitive fatigue (0–100 index) with supervisor alert triggers.
3. **Momentum Forecaster (`momentum_forecaster.py`):** Predicts resolution vs escalation trajectories with up to 95% confidence and projected turns to completion.
4. **Micro-Habit Coach (`habit_coach.py`):** Audits historical performance to issue personalized daily communication practice cards.
5. **FAISS Vector Knowledge Base (`knowledge_base.py`):** Dense 384d semantic search that surfaces exact company policies in `<10ms`.
